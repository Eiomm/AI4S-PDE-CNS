自主实验闭环

LLM 不再只输出普通建议，而是每轮必须生成一个结构化原子实验节点。节点进入 journal 后由受控 executor 执行，再由 reviewer 写回结果。

Observe State
Plan CandidateNode
Execute Action
Evaluate Metrics
Review Node
Select Next

节点 schema

{
  "intent": "draft|improve|debug|submit|stop",
  "hypothesis": "one scientific reason",
  "action_type": "weight_search|finetune|code_patch|baseline_train|baseline_validate|baseline_ensemble|baseline_refine|submit_best|stop",
  "params": {},
  "expected_effect": "metric or reliability change",
  "risk": "what can go wrong"
}
Action 允许范围 后续校验
weight_search 搜索 FNO checkpoint / fine-tuned checkpoint 的 ensemble 权重 写入 validation metrics，按目标 metric 选 best
finetune 运行已有 fine-tune 脚本，控制步数、学习率、样本数、选择指标 保存 checkpoint、metrics、stdout/stderr tail
code_patch 允许重写 code/ 下提交源码，包括较大改动；必须携带 validation_command 或 submission_validation_path 路径不能越出 code/；验证命令或提交校验失败则节点失败并进入 debug；提交校验包含 code-log consistency
baseline_train / baseline_validate 运行 Baseline Zoo 中的 FNO、TFNO、U-Net、DeepONetLite、PINO-FNO、Residual Refiner 候选 写入 metrics.json、run_result.json、experiment_memory.json、baseline_manifest.json
baseline_ensemble / baseline_refine 基于验证集 prediction 做 global convex ensemble、feature-cluster EM 或 residual correction 只允许 validation gate 通过的候选进入提交生成阶段
submit_best 用 journal 中最优权重或显式权重生成提交包 validate_submission 与 pred.zip 规则

接下来三阶段方案

Phase 1：把自主实验跑稳

马上做

  • 完成 为 planner 增加 PDE 专用 prompt，强制优先提出低成本可验证实验。
  • 完成 code_patch 支持 validation_command 与 submission_validation_path，失败节点自动进入 debug 方向。
  • 完成 把 journal.json 转成可读 journal_report.md。
  • 完成 autonomous CLI 默认开启 strict gate，防止只改代码不验证。

Phase 2：Task 1 冲分实验库

高优先级

  • 短训 fine-tune grid：学习率、步数、样本段、选择指标。
  • Baseline Zoo：FNO、TFNO、U-Net、DeepONetLite、PINO-FNO、Residual Refiner 统一接口。
  • 多步 rollout loss：降低长时漂移。
  • 谱域 loss：针对 Burgers 高频误差。
  • physics residual / conservation proxy：增强科学合理性。
  • global / feature-cluster EM ensemble：根据初值动态特征选择专家。
  • temporal tail blend：当某个模型只在后段更强时，只融合长时段预测。
  • 结果台账：每次实验自动汇总到 docs/results/task1_experiment_results.md。

Phase 3：Task 2 从头训练

必须隔离

  • 建立 Task 2 独立 TaskSpec、dataset、workflow、metrics。
  • 从零训练 nu-conditioned FNO / DeepONet，不用 Task 1 checkpoint。
  • 建立 12 小时预算内的多保真训练策略。
  • 生成 Task 2 独立 methodology 与日志证据。

神经算子优化策略库

必做保底项

  • 统一指标面板：MSE、forecast MSE、segment score、proxy score。
  • baseline 复现：官方 FNO checkpoint、fine-tuned FNO、ensemble。
  • Baseline Zoo 复现：U-Net、DeepONetLite、Residual Refiner prototype。
  • 多保真评估：小样本、小步数先筛分支。
  • 短训防退化：只有验证优于 base 才保存 best.pt。
  • 提交审计：prediction shape、前 10 帧、code trace、zip 内容。

冲榜创新项

  • PINO / physics residual：把 Burgers 方程约束纳入 fine-tune。
  • 谱域高频 loss：降低 shock 附近误差。
  • PDE-Refiner：对长时 rollout 后段做 correction。
  • TFNO / F-FNO 分支：在算力允许时替换 backbone。
  • specialist ensemble：按 nu / dynamics / 初值 shock 特征分区融合。

评分对齐

评分维度 仓库落点 下一步增强
科学性能 pde_metrics.py、evaluate_task1.py、Baseline Zoo + ensemble 补 TFNO / PINO-FNO 中等规模训练和更强 residual refiner。
探索效率 WeightedEnsembleSearch、Baseline Zoo prototype、validation-first workflow 增加模型级晋级规则和 cluster/gating 只在 global ensemble 有收益后启用。
演进逻辑严密性 ExperimentJournal、CandidateNode、planner logs 生成人类可读实验报告，展示 hypothesis → patch → metric → decision。
提交合规 validate_submission、code_trace.py、pred.zip 每次 autonomous submit 自动解压复验。
