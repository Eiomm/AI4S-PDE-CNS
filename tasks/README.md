# AI4S PDE CNS Agent Prediction Tasks

This directory contains exactly three agent-facing prediction task descriptions.

These descriptions tell an Agent what data it may read and what prediction file
it must generate.

Tasks:

- `ai4s-pde-task1-burgers-fixed`: generate `task1_pred.hdf5`.
- `ai4s-pde-task2-burgers-multinu`: generate `task2_pred.hdf5`.
- `ai4s-pde-task3-ks-multiparam`: generate `task3_pred.hdf5`.
